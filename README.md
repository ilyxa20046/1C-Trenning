# 1С:Профессионал — тренажёр (961 вопрос)

Приложение для подготовки к экзамену **«1С:Профессионал» по платформе «1С:Предприятие 8»**
(Издание 2, версия сборника на июль 2021 г.). Полный список вопросов из сборника — 961 вопрос,
14 разделов, к каждому вопросу проставлен правильный ответ **и пояснение, почему он верный**.

## Что в папке

| Файл | Что это |
|---|---|
| `1c-profi.html` | **Веб-версия**: один файл, работает в любом браузере на ПК и телефоне без интернета. Просто откройте его двойным щелчком. |
| `1c-profi.apk` | **Android-приложение** (Android 6.0 и новее). |
| `web/` | Та же веб-версия + манифест и service worker: если выложить папку на любой хостинг, приложение можно «установить» на телефон и на ПК как обычное приложение (PWA). |
| `db.json` | База вопросов в JSON (961 вопрос) — для резервной копии и переноса. |
| `work/` | Исходники: парсер PDF, шаблон приложения, скрипт сборки APK. |

## Как установить на Android

1. Перекиньте `1c-profi.apk` на телефон (кабель, Telegram «Избранное», почта, облако).
2. Откройте файл в проводнике телефона → «Установить».
3. Если появится предупреждение «Установка из неизвестного источника запрещена» —
   нажмите «Настройки» и разрешите установку для этого приложения (проводника/браузера).
   Play Protect может спросить про непроверенное приложение — выберите «Всё равно установить»:
   APK подписан самодельным (debug) ключом, в магазине его нет.
4. После установки появится иконка «1С:Профессионал».

Приложение полностью офлайновое, никаких разрешений на интернет не требует.

## Как установить на компьютер

- **Проще всего:** откройте `1c-profi.html` двойным щелчком — откроется в браузере.
  Можно скопировать файл на рабочий стол и сделать ярлык.
- **Как приложение (Chrome/Edge):** выложите содержимое папки `web/` на любой хостинг
  (или запустите локальный веб-сервер) → откройте адрес → в адресной строке появится
  значок «Установить».

## Что умеет

- **Экзамен** — 14 случайных вопросов, по одному из каждого раздела, 30 минут, зачёт с 12 верных.
  Таймер, автозавершение по времени, разбор ошибок после попытки.
- **Билеты** — 69 фиксированных билетов по 14 вопросов (по одному из каждого раздела по кругу).
  Все 961 вопрос входят в билеты ровно по одному разу. В билете — мгновенная проверка с пояснением,
  на экране результата кнопка «Следующий билет →», у каждого билета виден статус (изучено / результат / сдан).
  Есть «Случайный билет» и фильтр «Только непройденные».
- **Быстрая тренировка** — 20 случайных вопросов с мгновенной проверкой и пояснением.
- **Тренировка по разделу** — вопросы выбранного раздела, «Проверить» + пояснение.
- **Повторить ошибки** — все вопросы, в которых вы ошибались.
- **Избранное** — отметить сложные вопросы звёздочкой.
- **Редактор вопросов** — полное редактирование: правка текста вопроса, вариантов ответа,
  отметка правильного варианта, пояснения; добавление новых вопросов; удаление;
  поиск по тексту/ответу/номеру и фильтр по разделу.
- **Импорт / экспорт JSON** — резервная копия и перенос базы между устройствами.
  На Android экспорт сохраняет файл в папку «Загрузки».
- **Тёмная и светлая тема**, крупные кнопки под палец, клавиатура на ПК: `1…9` — выбрать вариант,
  `Enter` — проверить/далее.
- **Прогресс сохраняется** автоматически в памяти устройства (localStorage).
  Кнопка «Восстановить исходные вопросы» в разделе «Импорт/экспорт» отменяет все правки.

## Важно про ответы

Официальный сборник содержит ответы только к двум демонстрационным заданиям. Ответы к остальным
961 вопросу подготовлены искусственным интеллектом на основе документации платформы и практики
1С; они выверены по формулировкам вариантов, но не являются официальным ключом фирмы «1С».
Если формулировка спорная — сверьтесь с документацией и поправьте ответ прямо в редакторе
(правка сохранится и будет учитываться в тренировках).

## Сборка APK из исходников

```bash
export JAVA_HOME=$HOME/.cache/jdk17
export ANDROID_HOME=$HOME/.cache/android/sdk     # platform android-34, build-tools 34.0.0
bash work/android/build.sh                        # aapt2 → javac → d8 → zipalign → apksigner
```

`work/android/assets/index.html` — это `1c-profi.html`, вшитый в APK. После правки шаблона
`work/app_template.html` пересоберите HTML подстановкой `db.json` вместо `__DATA__`, скопируйте
в `work/android/assets/index.html` и запустите `build.sh`.
